Session 07 — Bài tập 4

Cấu hình Reverse Proxy Nginx cho Spring Boot

Định tuyến lưu lượng tĩnh (Static Web) và chuyển tiếp API Backend

Họ và tên học viên: Nguyễn Mạnh Hùng
Mã lớp: DevOps_01
Trạng thái Nginx: 200 OK (Static Serve)
Thư mục tĩnh: /var/www/html/
Quy tắc định tuyến Nginx Path Matching:
GET / → Phục vụ trực tiếp từ /var/www/html/index.html
GET /api/* → Reverse Proxy chuyển tiếp tới http://127.0.0.1:8082/
Hệ thống triển khai trên Ubuntu 22.04 LTS • Nginx Reverse Proxy
