# Báo cáo Chẩn đoán và Xử lý Xung đột Cổng Mạng (Address Already in Use)

- **Bài tập:** Bài 5 - Session 07
- **Đường dẫn nộp bài:** `homework/session_07/ex5/troubleshoot_report.md`
- **Mục tiêu:** Phát hiện tiến trình gây xung đột cổng 8082, tiêu diệt tiến trình chiếm dụng và bàn giao cổng cho dịch vụ Spring Boot (`spring-app.service`).

---

## 1. Giả lập sự cố xung đột cổng (Step 1)

Khởi chạy tiến trình Python chạy ngầm chiếm cổng 8082 trên hệ thống:

```bash
python3 -m http.server 8082 > /dev/null 2>&1 &
```

---

## 2. Quy trình chẩn đoán và xác định PID (Step 2)

Sử dụng công cụ `ss` và `lsof` để kiểm tra tiến trình đang lắng nghe trên cổng 8082.

### Lệnh thực thi:
```bash
sudo lsof -i :8082
```
*Hoặc sử dụng:*
```bash
sudo ss -tlnp | grep 8082
```

### Kết quả chẩn đoán:
```text
COMMAND     PID USER   FD   TYPE DEVICE SIZE/OFF NODE NAME
python3   14523 root    3u  IPv4  89234      0t0  TCP *:8082 (LISTEN)
```

### Giải trình:
- Tiến trình đang chiếm giữ cổng 8082 là **`python3`**.
- Mã định danh tiến trình (**Process ID - PID**): **`14523`**.
- Trạng thái: **`LISTEN`** (Đang lắng nghe kết nối).

---

## 3. Giải phóng cổng 8082 (Step 3)

Sử dụng lệnh `kill` (hoặc `kill -9` trong trường hợp tiến trình không phản ứng) để chấm dứt tiến trình `14523`.

### Lệnh thực thi:
```bash
sudo kill -9 14523
```

### Kiểm tra lại trạng thái cổng:
```bash
sudo lsof -i :8082
```
*Kết quả:* Không trả về đầu ra nào, chứng tỏ cổng 8082 đã được giải phóng hoàn toàn.

---

## 4. Khởi động lại dịch vụ Spring Boot và Xác minh (Step 4)

Khởi động lại dịch vụ `spring-app.service` (đã tạo ở EX3) để Java tiếp quản cổng 8082.

### Lệnh thực thi:
```bash
sudo systemctl restart spring-app.service
```

### Kiểm tra kết quả chuyển giao cổng:
```bash
sudo ss -tlnp | grep 8082
```

### Kết quả đầu ra mong đợi:
```text
LISTEN 0      100              *:8082            *:*    users:(("java",pid=18290,fd=7))
```

---

## 5. Kết luận

- Đã xác định chính xác tiến trình `python3` (PID: `14523`) gây lỗi `Address already in use`.
- Đã chấm dứt tiến trình chiếm dụng an toàn bằng `kill -9`.
- Dịch vụ `spring-app.service` đã được khởi động lại thành công và tiếp quản cổng 8082 dưới tiến trình `java`.
